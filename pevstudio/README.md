# PEV Studio (ฉบับใช้งานแบบไม่เชื่อมต่อ AI)

เครื่องมือสำหรับคณะผู้ตรวจประเมินหลักสูตร (PEV) ของ TABEE ใช้ตรวจหลักสูตรตาม PEV Worksheet Ver.3 ครบ 8 เกณฑ์ 79 ข้อ ตั้งแต่ Auto Check, Pre-visit 1, ขอเอกสารเพิ่มเติม, Pre-visit 2, แผนและนัดตรวจเยี่ยม, Visit Day 1–2, Exit Statement จนถึง Fact Finding Report, Decision Meeting, รายงานผลการตรวจรับรอง และหนังสือแจ้งผล

ฉบับนี้ไม่เรียกใช้ AI หรือบริการภายนอกใด ๆ การตรวจเบื้องต้นใช้อัลกอริทึมค้นหลักฐานที่ทำงานในเบราว์เซอร์ทั้งหมด

## ข้อมูลของหลักสูตรอยู่ที่ไหน

- **ไฟล์ที่อัปโหลดและผลประเมินทั้งหมดเก็บในเบราว์เซอร์ของผู้ใช้แต่ละเครื่อง** (IndexedDB) ไม่ถูกส่งไปที่ GitHub หรือเซิร์ฟเวอร์ใด
- **หน้าเว็บไม่โหลดอะไรจากภายนอก** ไลบรารีและฟอนต์ทั้งหมดอยู่ในโฟลเดอร์ `lib/` และ `fonts/` ของ repository นี้
- **เบราว์เซอร์ช่วยกันอีกชั้น** ไฟล์ `index.html` กำหนด Content-Security-Policy ให้โหลดสคริปต์ ฟอนต์ และภาพจาก repository นี้เท่านั้น และส่งคำขอข้อมูล (fetch) หรือส่งฟอร์มไปยังโดเมนอื่นไม่ได้ ตรวจสอบได้จาก Developer Tools แท็บ Network ว่าไม่มีการเชื่อมต่อออกนอก repository
- **สิ่งที่อยู่บน GitHub มีเพียงโค้ดของโปรแกรม** ไม่มีข้อมูลหลักสูตรใด ๆ

ข้อควรระวัง

1. **อย่า commit ไฟล์ที่ได้จากปุ่ม Save (.json) หรือไฟล์ที่ส่งออก** ลงใน repository เพราะไฟล์เหล่านั้นมีข้อมูลของหลักสูตร
2. **หน้าเว็บบน GitHub Pages เปิดได้ทุกคนที่มีลิงก์** แม้ repository จะเป็น private ก็ตาม (การทำ Pages จาก private repository ต้องใช้ GitHub Pro, Team หรือ Enterprise) คนที่เปิดลิงก์จะเห็นแค่โปรแกรมเปล่า ไม่เห็นข้อมูลของใคร
3. **ข้อมูลอยู่ในเบราว์เซอร์จนกว่าจะล้าง** ถ้าใช้เครื่องสาธารณะ ให้กด Reset หรือล้างข้อมูลเว็บไซต์เมื่อใช้งานเสร็จ

## วิธีนำขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมไฟล์ `.nojekyll`)
2. ไปที่ Settings → Pages → Build and deployment เลือก Source เป็น `Deploy from a branch` แล้วเลือก branch `main` และโฟลเดอร์ `/ (root)`
3. รอประมาณ 1–2 นาที แล้วเปิดลิงก์ที่ GitHub แสดง เช่น `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repository>/`

หากไม่ต้องการนำขึ้นอินเทอร์เน็ต ใช้ในเครื่องได้ด้วยคำสั่ง `python -m http.server 8000` ในโฟลเดอร์นี้ แล้วเปิด `http://localhost:8000` (การเปิด `index.html` ด้วยการดับเบิลคลิกโดยตรงอาจอ่านไฟล์ PDF ไม่ได้)

## การทำงานเป็นทีม

ฉบับนี้ไม่มีเซิร์ฟเวอร์กลาง ข้อมูลของแต่ละคนจึงอยู่ในเครื่องของตนเอง วิธีแลกเปลี่ยนคือกด **Save** เพื่อได้ไฟล์งาน (.json) แล้วส่งให้สมาชิกในทีมผ่านช่องทางที่สถาบันอนุญาต ผู้รับกด **Open** เพื่อเปิดไฟล์นั้น ระบบเปิดเป็นรายการใหม่โดยไม่ทับงานเดิม

## Auto Check ตรวจอะไร

Auto Check ไม่ได้ "อ่านเข้าใจ" เนื้อหาแบบ AI แต่ทำ 3 อย่าง

1. **หาส่วนของแต่ละเกณฑ์** จากหัวข้อ "เกณฑ์ข้อ N" และหัวข้อย่อยตามแบบรายงานประเมินตนเอง (1. 2. 3. … และ 1.1 1.2 …)
2. **ค้นหลักฐานที่แต่ละข้อต้องการ** ตามกฎในไฟล์ `js/rules.js` เช่น ข้อ 1.2 ของเกณฑ์ข้อ 1 ต้องพบจำนวนรับเข้า การแยกตามวิธีรับเข้า และข้อมูลอย่างน้อย 4 ปีการศึกษา แล้วให้สีตามสัดส่วนหลักฐานที่พบ พร้อมบอกว่าพบที่ไฟล์ใด หน้าใด
3. **สัญญาณให้ตรวจเพิ่ม** ดึงข้อความที่ควรอ่านละเอียดออกมาแสดง เช่น "ต่ำกว่าเป้าหมาย", "กำชับ", "51 จาก 60 คน", อัตราตอบกลับแบบสอบถามต่ำกว่าร้อยละ 30 ส่วนนี้ไม่มีผลต่อสีของข้อ

| สี | ความหมายใน Auto Check |
|---|---|
| เขียว | พบหลักฐานครบทุกรายการ |
| เหลือง (Remark) | พบหลักฐานหลักครบ แต่ไม่พบหลักฐานเสริม |
| ส้มน้ำตาล (Concern) | คะแนนหลักฐานตั้งแต่ 67% เช่น พบหลักฐานแต่เล่มไม่มีหัวข้อของข้อนั้น |
| น้ำเงิน (Weakness) | คะแนนหลักฐานตั้งแต่ 34% เช่น เล่มไม่มีส่วนของเกณฑ์นั้นเลย |
| แดง (Deficiency) | คะแนนหลักฐานต่ำกว่า 34% |

**ข้อจำกัด** Auto Check บอกได้ว่ามีหรือไม่มีหลักฐาน แต่ตัดสินคุณภาพของหลักฐานไม่ได้ เช่น ตรวจไม่ได้ว่าอัตราตอบกลับแบบสอบถามเพียงพอหรือไม่ หรือมาตรการปรับปรุงได้ผลหรือไม่ ผลนี้จึงเป็นจุดตั้งต้นให้คณะผู้ตรวจพิจารณาใน Pre-visit 1 ไม่ใช่ผลการประเมิน นอกจากนี้

- ไฟล์ PDF ที่เป็นภาพสแกน หรือ PDF ที่ฝังฟอนต์ไทยแบบเก่า อาจดึงข้อความได้ไม่ถูกต้อง ควรใช้ไฟล์ Word ของ SER ถ้ามี
- ถ้าหัวข้อย่อยของ SER ไม่ได้แยกเป็นบรรทัดของตัวเอง อาจขึ้นหมายเหตุ "ไม่พบหัวข้อย่อย" ทั้งที่มีเนื้อหาอยู่ ให้ผู้ตรวจยืนยันเอง

ปรับคำค้นหรือเกณฑ์การให้สีได้ที่ไฟล์ `js/rules.js` โดยไม่ต้องแก้ไฟล์อื่น

## เอกสารที่สร้างได้

PEV Worksheet (.xlsx), แบบรายการขอรับคำอธิบายและเอกสารประกอบเพิ่มเติม, แบบขอนัดวันตรวจเยี่ยมสถาบันการศึกษา, แผนการตรวจเยี่ยม, ประเด็นและคำถามสัมภาษณ์, แบบรายการรายงานคำแถลงข้อเท็จจริง (Fact Finding), Program Decision (.pptx), แบบรายงานผลการตรวจรับรองมาตรฐานคุณภาพการศึกษา และหนังสือแจ้งผล (.docx) หรือสร้างทุกฉบับเป็นไฟล์ .zip
